# Atomic — Habit Tracker

A habit tracker for your phone, built on the ideas in *Atomic Habits* by James Clear.
It installs to your home screen, works without internet, and keeps all your data on your phone.

## What's inside
- **Today**: check off habits, use the 2-minute version on hard days, add notes, fill in a missed day.
- **Never miss twice**: one missed day pauses your streak; two in a row resets it.
- **Habit stacking**: "After I brush my teeth, I will read 10 pages." Stacked habits show in order.
- **Identity votes**: each habit counts as a vote for who you want to become.
- **Breaking bad habits**: track clean days and log slips.
- **Progress**: streaks, completion rates, calendar grids, total check-ins.
- **Habits Scorecard**: rate your current daily routines as +, = or −.
- **Backup / restore**: save a backup file and restore it on a new phone.

## For developers
```bash
npm install
npm run dev     # local preview
npm test        # streak logic tests
npm run build   # production build into dist/
```
To publish a new version to GitHub Pages: `npm run deploy`.
